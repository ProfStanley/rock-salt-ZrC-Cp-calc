The main calculations are in the Cp_calc folder, which has it's own README and scripts with comments and explanations

Electronic_DOS: This folder contains the results of the electron density of states, particularly looking around the Fermi level.  
SIESTA version 4.1.5 calculated the fermi level in this case to be ~-4.65 eV.  6x6x6 monkhorst pack was used in the paper.

The Optimize_LC has the (final) calculations that were used to calculate the optimal lattice constant for the simple cubic (rock salt) ZrC 64.

The manuscript, as of this writing is not yet published, but the preprint is available here in this directory as a pdf.
